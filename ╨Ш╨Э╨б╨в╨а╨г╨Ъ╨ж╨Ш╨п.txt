ARXHLTV — локальная админка с ручной публикацией

СОСТАВ
- index.html — сайт с локальной админкой и публикацией через GitHub API.
- start-local.bat — запуск локального сайта на Windows.
- original-site.zip — исходный архив до переделки (резервная копия).

ВАЖНО ПЕРЕД ПЕРЕХОДОМ
Сначала открой действующий опубликованный сайт и войди в старую админку, пока текущая версия ещё не заменена.
Скачай через «Скачать полную копию JSON» актуальные данные из действующей базы.
После этого распакуй новый архив в отдельную папку и запусти start-local.bat.
В локальной админке открой «Вход администратора», задай новый пароль (от 8 символов), затем зайди в раздел системных настроек.
Импортируй старый JSON через «Восстановить из JSON». Проверь команды, игроков, матчи и турниры.

ЗАПУСК
1. На Windows должен быть установлен Python 3.
2. Дважды нажми start-local.bat.
3. Откроется http://127.0.0.1:8000/.
4. Админка работает только в этой локальной версии на этом ПК.

НАСТРОЙКА ПУБЛИКАЦИИ
1. Создай Fine-grained Personal Access Token в GitHub.
2. Ограничь токен только репозиторием ARXHLTV.
3. Дай Contents: Read and write (Metadata: Read-only обычно добавляется автоматически).
4. Не включай токен в код, не отправляй его другим людям.
5. В локальной админке укажи владельца репозитория, имя репозитория, ветку и путь.
   По умолчанию указаны owner=arxhltv, repo=ARXHLTV, branch=main, path=arxhltv-state.json.
   Если основная ветка репозитория называется иначе, измени branch.
6. Вставь токен, нажми «Сохранить настройки».
7. После изменения данных нажимай «Опубликовать обновления».

КАК ЭТО РАБОТАЕТ
- Локальная версия сохраняет данные в браузере на этом ПК.
- Дополнительные автоматические снимки данных хранятся в IndexedDB этого браузера (последние 7 снимков).
- Публичный GitHub Pages сайт читает arxhltv-state.json и не имеет доступа к токену.
- Посетители увидят изменения после публикации и обновления GitHub Pages.
- Не очищай данные сайта/браузера на локальном ПК. Регулярно скачивай «полную копию JSON» на отдельный диск.
- Публикация заменяет JSON-файл в указанной ветке, но не переписывает index.html.

ОГРАНИЧЕНИЯ
- Это локальная админка для одного ПК и одного браузерного профиля.
- Если перенесёшь админку на другой ПК или очистишь данные браузера, перенеси резервный JSON и заново настрой пароль и GitHub-токен.
- GitHub Pages может обновлять статический файл не мгновенно.
- Перед заменой опубликованного index.html обязательно проверь импорт данных из старой базы.
