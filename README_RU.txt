ARXHLTV — версия с разделом «Турниры»

ЧТО ДОБАВЛЕНО
- Раздел «Турниры» в верхнем меню.
- Добавление турнира из админ-панели: название, логотип, дата и статус.
- Для завершённого турнира: 1–3 место, очки за места, MVP и очки MVP.
- Карточки турниров на отдельной странице.
- Блок «Ближайший турнир» на главной странице.
- Удаление турниров из админ-панели.
- Экспорт и импорт резервной копии данных в JSON, чтобы перенести данные на новый домен/хостинг.

КАК ОПУБЛИКОВАТЬ САЙТ ЧЕРЕЗ GITHUB PAGES
1. Создай репозиторий на GitHub, например ARXHLTV. Для бесплатного GitHub Pages репозиторий должен быть публичным.
2. Распакуй архив и загрузи index.html в корень репозитория (не загружай ZIP как единственный файл).
3. Открой Settings → Pages.
4. В Build and deployment выбери Deploy from a branch.
5. Выбери ветку main и папку /(root), нажми Save.
6. После публикации GitHub покажет адрес сайта вида https://ТВОЙ-ЛОГИН.github.io/ARXHLTV/.

ПЕРЕНОС ТЕКУЩИХ ДАННЫХ
Перед переездом открой старую версию сайта, зайди в админ-панель и нажми «Экспорт данных». На новой опубликованной версии открой админ-панель, выбери «Импорт данных» и загрузи сохранённый arxhltv-backup.json.

ВАЖНО ПРО ДАННЫЕ И АДМИНКУ
Эта версия пока статическая: команды, игроки, матчи и турниры сохраняются в LocalStorage браузера. Поэтому изменения, сделанные на одном устройстве/в одном браузере, не появятся автоматически у остальных посетителей.

Текущая проверка пароля админ-панели также находится на стороне браузера и не является безопасной для публичного сайта: пароль можно обнаружить в исходном JavaScript. Не используй эту версию для защищённого управления публичным рейтингом. Для полноценной работы всем посетителям нужна серверная база данных и серверная авторизация администратора (например, Supabase с правилами доступа/RLS или собственный backend). Не размещай секретные ключи в index.html.
